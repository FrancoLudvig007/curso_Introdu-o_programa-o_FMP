Retomada

Do while ao for

Na Aula 08 contamos até 5 com while. Se já sabemos que queremos repetir cinco vezes, existe uma forma mais direta?
while — controle manual 
contador = 1
while contador <= 5:
    print(contador)
    contador += 1
for — o mesmo resultado 
for numero in range(5):
    print(numero)

# exibe: 0 1 2 3 4

Conceito 1

O for percorre uma sequência

range(5) produz os números de 0 a 4 — o bloco executa uma vez para cada valor.

Python 
for numero in range(5):
    print(numero)
Saída 
0
1
2
3
4

A variável numero recebe automaticamente cada valor da sequência — sem incremento manual.

range(5) começa em 0 e termina antes de 5 — são 5 valores: 0, 1, 2, 3, 4.

Conceito 2

A função range() nas três formas

ExpressãoValores produzidos
range(4)0, 1, 2, 3
range(1, 5)1, 2, 3, 4
range(2, 10, 2)2, 4, 6, 8
range(5, 0, -1)5, 4, 3, 2, 1
Passo negativo: contagem regressiva 
for numero in range(5, 0, -1):
    print(numero)

# 5 4 3 2 1 — fogos de artifício!

1ª forma: até onde ir · 2ª: de onde a onde · 3ª: + o passo.

O limite final nunca é incluído — em nenhuma forma.

Conceito 3

Repetições com quantidade definida

3 tentativas garantidas 
for tentativa in range(3):
    print("Tentativa", tentativa + 1)
Saída 
Tentativa 1
Tentativa 2
Tentativa 3

Por que tentativa + 1?

A contagem interna começa em 0 (0, 1, 2), mas para o usuário faz mais sentido exibir 1, 2, 3.

Somamos 1 apenas na hora de exibir — a lógica do laço permanece natural.

Conceito 4

Acumuladores com for — e a média de 3 notas

Somando de 1 a 5 
soma = 0

for numero in range(1, 6):
    soma = soma + numero

print("Soma:", soma)   # 15
Média de 3 notas — integra tudo! 
soma = 0

for i in range(3):
    nota = float(input("Digite uma nota: "))
    soma += nota

media = soma / 3
print("Média:", media)

O laço pede três notas e acumula; a média é calculada após o término do for. O problema-guia do curso, agora elegante.

Conceito 5

while × for: quando usar cada um?

while

  • Repete enquanto uma condição for verdadeira
  • Ideal quando não se sabe quantas repetições serão necessárias
  • Exige atualização manual da variável de controle

Ex.: senha — repete até acertar, não importa quantas tentativas.

for

  • Percorre uma sequência de valores
  • Ideal quando a quantidade é conhecida
  • A variável recebe automaticamente cada valor

Ex.: tabuada, média de 3 notas, contar até 10.

Cuidado

A pegadinha do range(1, 10)

Errado — a tabuada para no 9 
for n in range(1, 10):
    print(n)

# 1 2 3 ... 9 — faltou o 10!
Correto — vai até 10 
for n in range(1, 11):
    print(n)

# 1 2 3 ... 10 ✓
Para incluir o 10, o limite precisa ser 11 — porque o fim do range não é incluído.

Fechamento

O que levamos desta aula

for

Percorre uma sequência de valores.

range()

Gera sequências — em 1, 2 ou 3 argumentos.

Limite exclusivo

O fim do range nunca é incluído.

Passo

Controla o intervalo — inclusive negativo.

Quantidade conhecida → for

Quantidade desconhecida → while.

Acumuladores

Funcionam dentro do for como no while.
