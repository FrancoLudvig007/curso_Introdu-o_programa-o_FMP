Conceito 1

O que é uma lista?

Uma coleção ordenada de elementos, separados por vírgulas e delimitados por colchetes.

Listas de diferentes tipos 
notas = [8.0, 7.5, 9.0, 6.5]
nomes = ["Ana", "Bruno", "Carla"]
dados = ["Ana", 19, 1.68, True]

Observações

  • Uma lista pode misturar tipos (str, int, float, bool…)
  • Mas listas com elementos de mesma finalidade (ex.: só notas) organizam melhor o programa
  • A ordem importa: a lista guarda a posição de cada elemento

Conceito 2

Índices: o acesso pela posição

Em Python, os índices começam em zero.

índice:      0        1        2
           +--------+--------+--------+
nomes   =  | "Ana"  | "Bruno"| "Carla"|
           +--------+--------+--------+
Acessando 
print(nomes[0])   # Ana
print(nomes[1])   # Bruno
print(nomes[2])   # Carla
Índice inexistente = erro 
print(nomes[3])   # IndexError!

Erro de execução (Aula 07): a lista tem posições 0, 1 e 2 — a 3 não existe.

Conceitos 3 e 4

Alterar elementos e medir a lista

Substituir pelo índice 
nomes = ["Ana", "Bruno", "Carla"]

nomes[1] = "Beatriz"

print(nomes)
# ['Ana', 'Beatriz', 'Carla']
len() — quantos elementos? 
nomes = ["Ana", "Bruno", "Carla"]

print(len(nomes))   # 3
Com 3 elementos, os índices vão de 0 a 2 — mas o tamanho é 3. Essa diferença evita o IndexError ao percorrer.

Conceito 5

Adicionar e remover elementos

append() — adiciona ao final 
nomes = ["Ana", "Bruno"]

nomes.append("Carla")

print(nomes)
# ['Ana', 'Bruno', 'Carla']
remove() — primeira ocorrência 
nomes = ["Ana", "Bruno", "Carla"]

nomes.remove("Bruno")

print(nomes)
# ['Ana', 'Carla']

remove() procura pelo valor. Se ele não estiver na lista, gera um erro de execução.

Conceito 6

Percorrer uma lista com for

Duas formas — direto pelos valores, ou pelos índices.

Direto pelos valores 
for nome in nomes:
    print(nome)

# Ana
# Bruno
# Carla
Pelos índices (com a posição) 
for i in range(len(nomes)):
    print(i, nomes[i])

# 0 Ana
# 1 Bruno
# 2 Carla

Use a forma por índices quando precisar da posição além do valor.

Conceito 7

Listas numéricas: soma e média

len() substitui a contagem manual — funciona para qualquer tamanho de lista.

Soma com acumulador 
notas = [8.0, 7.5, 9.0]
soma = 0

for nota in notas:
    soma += nota

print("Soma:", soma)   # 24.5
Média com len() 
media = soma / len(notas)
print("Média:", media)  # 8.166...

Adicione 10 notas à lista — o mesmo código continua funcionando, sem alterar nada.

Exercício de fixação

Registro de notas

O desafio

Tema: listas + repetição + acumulador.

Tarefa: receber cinco notas, armazená-las em uma lista e exibir todas as notas, a soma e a média.

Mobiliza: lista vazia, append(), for, range(), acumulador, len(), print().

Comece com uma lista vazia

notas = [] — e cresça com append().

Laço de 5 voltas

for i in range(5): cada volta pede uma nota.

Segundo laço para a soma

Percorra a lista acumulando os valores.

Média com len()

soma / len(notas) — sem escrever "5" no código.

Notas: [8.0, 7.0, 9.0, 6.0, 10.0]
Soma: 40.0
Média: 8.0
