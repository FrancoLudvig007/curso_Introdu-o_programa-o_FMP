Retomada

Do cálculo à decisão

Nosso programa de compras calcula o total. Mas… e se quisermos conceder desconto quando o valor passar de um limite?

Até agora, os programas executaram instruções em sequência. Uma condição permite selecionar um caminho — usando os operadores relacionais e lógicos da Aula 05.

Conceito 1

Estrutura if — o caminho único

Python 
idade = 20

if idade >= 18:
    print("Maior de idade")
Condição falsa → bloco ignorado 
idade = 16

if idade >= 18:
    print("Maior de idade")

print("Programa encerrado")

Anatomia do if

  • if — inicia a condição
  • idade >= 18 — expressão avaliada (True/False)
  • : — indica o início do bloco
  • Indentação — identifica as instruções do bloco

Saída do segundo exemplo: apenas Programa encerrado — o print indentado não executa.

Conceito 2

Estrutura if/else — dois caminhos

Python 
idade = int(input("Digite sua idade: "))

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")

Fluxo da decisão

        idade >= 18?
           /      \
         Sim      Não
          |        |
    Maior de   Menor de
     idade      idade

Pergunta: se a idade for exatamente 18, qual caminho executa? Por quê?

O bloco if roda quando a condição é verdadeira; o else, quando é falsa. >= inclui o limite — 18 é "maior ou igual".

Conceito 3

Estrutura if/elif/else — três ou mais caminhos

As condições são verificadas de cima para baixo. Quando uma é verdadeira, seu bloco executa e as demais são ignoradas.

Classificar uma nota 
nota = float(input("Digite a nota: "))

if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")

Como o Python lê

  • Nota 8.5 → 1ª condição verdadeira → Aprovado
  • Nota 6.0 → 1ª falsa, 2ª verdadeira → Recuperação
  • Nota 4.5 → todas falsas → Reprovado
A ordem das condições é decisiva — veja o próximo slide.

Cuidado

O erro de ordem das condições

Errado — para nota 9 
nota = 9

if nota >= 5:
    print("Recuperação")   # executa aqui!
elif nota >= 7:
    print("Aprovado")      # nunca chega

A condição nota >= 5 já é verdadeira para 9. O bloco dela roda primeiro e o resto é ignorado.

Correto — do mais restritivo ao mais amplo 
nota = 9

if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")

O programa não "entende a intenção": executa as condições na ordem escrita.

Boa prática

Indentação e blocos de código

Em Python, a indentação define quais instruções pertencem a cada bloco.

O que pertence ao if? 
idade = 20

if idade >= 18:
    print("Maior de idade")
    print("Pode seguir para a próxima etapa")

print("Fim")

Leitura

  • Os dois primeiros print() estão dentro do if (indentados)
  • O último print() está fora — executa sempre
  • Indentação errada pode causar erro de sintaxe ou alterar a lógica

Padrão da comunidade: 4 espaços por nível de indentação.

O desafio

Tema: decisão com três caminhos.

Tarefa: receber a nota de um estudante e informar Aprovado (≥ 7), Recuperação (entre 5 e 6,99) ou Reprovado (< 5).

Mobiliza: input(), float(), operadores relacionais, if/elif/else, print().

Defina os intervalos antes de programar

Comece pela aprovação

Da condição mais restritiva para a mais ampla.

Teste as fronteiras

Execute com 7, 5 e 4.9 — os valores que separam os caminhos.

Confira a indentação

Cada print dentro do seu bloco.
