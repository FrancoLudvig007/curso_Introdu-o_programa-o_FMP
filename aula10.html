Conceito 1

Condição dentro de um laço

O for fornece os valores; o if decide quais recebem tratamento especial.

Pares de 1 a 10 
for numero in range(1, 11):
    if numero % 2 == 0:
        print(numero)
Saída 
2
4
6
8
10

Como o Python executa

  1. O for fornece um número
  2. O if verifica o resto da divisão por 2
  3. Resto 0 → o número é exibido
  4. O laço recebe o próximo número

O truque do % da Aula 05, agora dentro do laço.

Conceito 2

Acumular apenas os que atendem à condição

Somar só os pares 
soma = 0

for numero in range(1, 11):
    if numero % 2 == 0:
        soma += numero

print("Soma dos pares:", soma)

Saída: 30 — a soma só é atualizada quando a condição é verdadeira.

Contar ocorrências — divisíveis por 3 
quantidade = 0

for numero in range(1, 21):
    if numero % 3 == 0:
        quantidade += 1

print("Quantidade:", quantidade)   # 6

Contador soma sempre 1; acumulador soma valores que variam.

Conceito 3

Validação de entrada: while + try/except

A Aula 07 avisou sobre o erro; agora o programa insiste até receber um dado válido.

Repetir até a conversão funcionar 
valido = False

while not valido:
    try:
        idade = int(input("Digite sua idade: "))
        valido = True
    except ValueError:
        print("Entrada inválida. Digite apenas números.")

print("Idade registrada:", idade)

Como funciona

  • valido é uma "bandeira": começa falsa
  • Conversão bem-sucedida → a bandeira vira True → o laço termina
  • ValueError → o except avisa → o laço repete

O programa só segue adiante com um dado confiável — sem quebrar nunca.

Conceito 4

Menu interativo: while + if/elif

Programa bancário simples 
opcao = ""

while opcao != "4":
    print("1 - Saldo | 2 - Depositar")
    print("3 - Sacar  | 4 - Sair")
    opcao = input("Escolha: ")

    if opcao == "1":
        print("Saldo: R$ 100.00")
    elif opcao == "2":
        print("Depósito realizado.")
    elif opcao == "3":
        print("Saque realizado.")
    elif opcao == "4":
        print("Até logo!")
    else:
        print("Opção inválida.")

Leitura do programa

  • O menu é exibido a cada volta do while
  • A opção "4" encerra — a condição do laço
  • O else final captura opções inexistentes
  • É assim que funcionam sistemas com telas e opções

Conceito 5

Laços aninhados: for dentro de for

Um laço externo controla as rodadas; um interno percorre tudo dentro de cada rodada.

Tabuadas de 1 a 3 
for tab in range(1, 4):
    print(f"Tabuada do {tab}")
    for n in range(1, 11):
        print(f"{tab} x {n} = {tab * n}")
    print()   # linha em branco entre tabuadas

Como lê

  • O laço externo escolhe a tabuada (1, depois 2, depois 3)
  • Para cada tabuada, o laço interno completa o 1 ao 10
  • O print() vazio separa visualmente as tabuadas
A indentação define quem está dentro de quem — dois níveis de recuo = dois níveis de laço.

Cuidado

Dois erros clássicos em estruturas combinadas

1 · Acumulador inicializado DENTRO do laço 
for numero in range(1, 6):
    soma = 0      # zera a cada volta!
    soma += numero

print(soma)        # 5 — só o último

A variável é reiniciada a cada repetição. O resultado não é a soma de todos.

Correção — inicializar ANTES 
soma = 0           # antes do laço ✓

for numero in range(1, 6):
    soma += numero

print(soma)        # 15 ✓

Contadores e acumuladores que precisam preservar o resultado entre as voltas nascem fora do laço.

Lembre também: um print "desindentado" dentro de um for/if muda completamente o que ele executa.

Exercício de fixação

Soma dos pares até um limite

O desafio

Tema: integrar repetição, condição e acumulador.

Tarefa: solicitar um número inteiro positivo e somar todos os pares de 1 até esse número; exibir a soma ao final.

Mobiliza: input(), int(), for, range(), if, %, acumulador.

Defina o intervalo

De 1 até o limite — lembrando do +1 no range.

Filtre com % 2

Só some quando o resto for zero.

Soma começa em zero, fora do laço

Ela acumula entre as voltas.

Teste com 6 e com 1

Com limite 1 não há pares: a soma fica 0 — e está correto!
