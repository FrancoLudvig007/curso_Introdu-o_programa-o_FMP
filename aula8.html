Retomada

Por que precisamos repetir?

Com if, o programa decide se executa um bloco. Mas como pedir uma senha novamente quando ela está errada — sem escrever as mesmas instruções várias vezes?
Sem repetição 😖 
print("Olá")
print("Olá")
print("Olá")
Com repetição 😎 
contador = 0
while contador < 3:
    print("Olá")
    contador = contador + 1

Conceito 1

Anatomia do while

A condição é verificada antes de cada execução do bloco. Se for falsa de início, o bloco nunca roda.

Contando de 1 a 5 
contador = 1

while contador <= 5:
    print(contador)
    contador = contador + 1

Os seis passos do laço

  1. contador começa em 1
  2. Verifica contador <= 5
  3. Verdadeira → executa o bloco
  4. Contador é incrementado
  5. Condição verificada novamente
  6. Falsa → o laço termina

Conceito 2

Contadores e o operador +=

As duas escritas são equivalentes 
contador = contador + 1
contador += 1

O contador pode caminhar nos dois sentidos

  • Sobe: contando repetições (1, 2, 3…)
  • Desce: contagem regressiva (10, 9, 8…)
  • Pode avançar de 2 em 2, de 5 em 5…

O que importa: a variável de controle muda a cada volta, aproximando a condição do fim.

Cuidado

Laço infinito: quando o fim nunca chega

Errado — contador nunca muda 
contador = 1

while contador <= 3:
    print(contador)
    # faltou o contador += 1 !

A condição permanece verdadeira para sempre — o programa "trava" imprimindo 1. Para sair: Ctrl + C.

Correto 
contador = 1

while contador <= 3:
    print(contador)
    contador += 1   # caminha para o fim
Todo while precisa dos três elementos: 1. valor inicial · 2. condição de continuidade · 3. atualização da variável de controle.

Pergunta: se o contador começa em 1 e a condição é contador < 1, o bloco é executado alguma vez?

Conceito 3

Entrada controlada por while

Repetir uma solicitação até que o usuário informe um valor válido.

Python 
senha = input("Digite a senha: ")

while senha != "python123":
    print("Senha incorreta")
    senha = input("Tente novamente: ")

print("Acesso autorizado")

Fluxo

Solicita senha
     |
Senha correta? --Não--> solicita
     |                  novamente
     Sim                (loop)
     |
Acesso autorizado
A variável senha precisa receber um novo valor dentro do laço — senão a condição nunca muda (loop infinito!).

Conceito 4

Acumuladores

Um acumulador guarda um resultado que é atualizado a cada repetição.

Somar 1 + 2 + 3 + 4 + 5 
contador = 1
soma = 0

while contador <= 5:
    soma = soma + contador
    contador += 1

print("Soma:", soma)   # 15

contador controla quantas voltas · soma acumula os valores.

Tentativas de senha

O desafio

Tema: controlar um laço com contador, condição e decisão.

Tarefa: solicitar uma senha permitindo até 3 tentativas. Se correta: "Acesso autorizado". Se as três falharem: "Acesso bloqueado".

Mobiliza: while, contador, comparação, if/else.

Defina quando o laço continua

Enquanto houver tentativas E a senha estiver errada.

Crie o contador de tentativas

Começa em 1 e sobe a cada erro.
