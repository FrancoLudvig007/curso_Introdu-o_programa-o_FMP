Conceito 1

O que é um algoritmo?

A ferramenta central que organiza o pensamento antes de qualquer linha de código — agora formalizamos a prévia da Aula 02.

Algoritmo é uma sequência finita, ordenada e não ambígua de passos que leva à realização de uma tarefa ou à solução de um problema.

Passos compreensíveis

Cada instrução clara, sem duplo sentido.

Ordem lógica

Cronologia rigorosa: cada ação depende da anterior.

Finitude

Início, etapas intermediárias e término obrigatório.

Receita culinária, manual de montagem e guia de primeiros socorros são algoritmos em linguagem natural.

Conceito 2

Algoritmos no cotidiano: o piloto automático

O cérebro automatiza rotinas — mas uma máquina não tem intuição nem memória muscular: cada detalhe omitido é uma falha potencial.

Atravessar uma rua

Parar no meio-fio → olhar à esquerda → olhar à direita → avaliar a velocidade dos veículos → atravessar em linha reta.

Fazer uma ligação

Desbloquear a tela → abrir os contatos → buscar o nome → discar → aproximar do ouvido.

Sacar no caixa eletrônico

Inserir o cartão → digitar a senha → escolher saque e valor → recolher cartão, cédulas e comprovante.

Executamos essas ações quase sem pensar. Um programa precisa de cada passo explicitado.

Conceito 3

Decomposição extrema: "escovar os dentes"

A instrução "Acorde e vá escovar os dentes" basta para um humano. Para uma execução lógica: 30 passos numerados — agrupados aqui em 5 fases.

FASE 1 · PASSOS 1–3

Despertar

Ouvir o alarme; abrir os olhos; esticar o braço e desligá-lo na mesa de cabeceira.

FASE 2 · PASSOS 4–10

Deslocamento

Levantar; caminhar até o banheiro; acender a luz; parar diante da pia.

FASE 3 · PASSOS 11–20

Preparação

Pegar escova e pasta; girar a tampa (13); pressionar o tubo até sair pasta (15); umedecer as cerdas (19).

FASE 4 · PASSOS 21–23

Escovação

Escovar todas as faces dos dentes e a língua por 2 minutos; cuspir a espuma.

FASE 5 · PASSOS 24–30

Finalização

Enxaguar a boca; lavar e guardar a escova; secar o rosto; apagar a luz.

Sem o passo 13 (abrir a tampa da pasta), o passo 15 falha: nada sai do tubo. Ordem e completude não são opcionais.

Conceito 4 · Conexão com as Aulas 01–02

O computador é uma entidade literal

"Extremamente rápido, mas estritamente literal e sem iniciativa: ele não faz nada além do que foi detalhadamente instruído."

Não deduz intenções

Pediu a média de 3 notas e esqueceu de dividir por 3? Ele entrega a soma — sem desconfiar do equívoco.

Não corrige ambiguidades

Executa a ambiguidade até travar ou errar: lixo entra, lixo sai (GIGO).

Não pula etapas "óbvias"

Porta trancada sem instrução para girar a chave? A execução simplesmente para.

Programar é estruturar comandos com clareza suficiente para que uma máquina literal alcance exatamente o objetivo esperado.

Conceito 5

Estrutura padrão de um algoritmo textual

O modelo clássico de processamento de dados — a mesma espinha dorsal do modelo de Von Neumann (Aula 01).

ENTRADA DE DADOS

Informações necessárias que alimentam o processo

PROCESSAMENTO

Ações, cálculos, decisões e transformações

SAÍDA DE DADOS

Resultados apresentados ao usuário ou sistema

Exemplo — Preparar um suco de pacote (com INÍCIO e FIM)

ENTRADA (1–4): jarra de 1 L e colher; 1 litro de água filtrada; 1 envelope de suco em pó.

PROCESSAMENTO (5–9): abrir o envelope e despejar o pó na água; mexer por 30 segundos; se ainda houver pó no fundo, mexer por mais 15 segundos.

SAÍDA (10): servir o suco pronto em um copo.

Conceito 6

Conheça o Python

A linguagem que usaremos do início ao fim — hoje, apenas reconhecimento visual (sem editor e sem execução).

Criação

Concebida no final dos anos 1980 como projeto de hobby; primeira versão pública em 1991, por Guido van Rossum — matemático e programador holandês.

Origem do nome

Contrariando o senso comum, não é a serpente: vem do grupo de humor britânico Monty Python, do qual Guido era fã.

Linguagem de alto nível

Muito distante dos circuitos e do binário — palavras e construções próximas do inglês do dia a dia.

Neste curso

Nossa ferramenta do início ao fim — direto, sem etapa em Portugol (decisão da Aula 02).

Conceito 7

A filosofia: The Zen of Python

A cultura de clareza da linguagem, resumida em diretrizes escritas por Tim Peters.

"Bonito é melhor que feio."

"Explícito é melhor que implícito."

"Simples é melhor que complexo."

"Legibilidade conta."

"Se a implementação é difícil de explicar, é uma má ideia."

O resultado prático

  • Palavras-chave intuitivas e comandos diretos
  • Elementos puramente burocráticos são dispensados
  • Menos ruído visual — o foco fica na lógica da solução

The Zen of Python — Tim Peters (PEP 20)

A média das 3 notas — o problema-guia

O mesmo cálculo desenhado na Aula 02, agora em código real.

Em C++ 
#include <iostream>

int main() {
    float n1 = 7, n2 = 8, n3 = 9;
    float media = (n1 + n2 + n3) / 3;
    std::cout << "Media: " << media << std::endl;
    return 0;
}
Em Python 
n1 = 7
n2 = 8
n3 = 9

media = (n1 + n2 + n3) / 3
print("Media:", media)

Amostra 3 · C++ × Python

Tomada de decisão: maior de idade?

Em C++ 
#include <iostream>

int main() {
    int idade = 20;

    if (idade >= 18) {
        std::cout << "Acesso permitido." << std::endl;
    } else {
        std::cout << "Acesso negado." << std::endl;
    }
    return 0;
}
Em Python 
idade = 20

if idade >= 18:
    print("Acesso permitido.")
else:
    print("Acesso negado.")
Sem chaves { } delimitando blocosA indentação define o que está dentro do if/elseOs dois-pontos abrem cada bloco

Conceito 8

Anatomia das instruções que vimos

Os elementos fundamentais que compõem um programa em Python.

print(...)

Comando de saída: exibe algo na tela.

"texto"

Cadeia de caracteres: marcada por aspas.

numero1, idade

Variáveis: nomes de espaços de armazenamento.

=

Atribuição: guarda o valor da direita no nome da esquerda.

+ - * /

Aritméticos: executam os cálculos matemáticos.

>= == < !=

Comparações: resultam em True ou False.

if / else

Decisão: "se a condição vale, faça A; senão, faça B".

:

Dois-pontos: iniciam um bloco subordinado (indentado).

Exercício · Papel e caneta

Algoritmo para trocar uma lâmpada queimada

O desafio

Cenário: você entra em um quarto escuro, aciona o interruptor da parede — e a lâmpada do teto não acende.

Tarefa: escrever um algoritmo textual completo e numerado, do instante em que você nota o defeito até a lâmpada nova ser testada com sucesso e a antiga descartada.

Sem computador e sem editor: hoje, a lógica é toda sua.

Presuma a literalidade de quem executa

Instruções vagas como "troque com cuidado" são proibidas.

Segurança e verificação física

Interruptor/disjuntor desligado antes do contato com o bocal; escada estável; testar a temperatura da lâmpada queimada antes de desenroscar.

Validação do resultado

Religar a energia e testar; se a nova não acender, verificar se está bem rosqueada.

Formatação obrigatória

Marcação explícita de INÍCIO e FIM; no mínimo 12 passos numerados e sequenciais.
