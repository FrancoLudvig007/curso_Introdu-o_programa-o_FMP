Conceito 1

Três categorias de erro

Erro de sintaxe

O código não segue a gramática da linguagem. O programa nem começa.

Ex.: esquecer os dois-pontos do if.

Erro de execução

O programa inicia, mas falha no meio do caminho.

Ex.: converter "abc" para int; dividir por zero.

Erro lógico

O programa roda até o fim, mas com resultado errado.

Ex.: condições na ordem trocada (Aula 06).

O mais traiçoeiro é o erro lógico: o Python não reclama — quem precisa perceber é você, testando.

Categoria 1

Erros de sintaxe: SyntaxError

O Python aponta a linha e o problema antes de executar qualquer coisa.

Exemplos clássicos 
if idade >= 18      # faltou o :
    print("ok")

print("Olá          # faltou fechar aspas

print("Olá"          # faltou fechar parêntese

Como o Python avisa

  File "programa.py", line 3
    if idade >= 18
                 ^
SyntaxError: expected ':'
  • O circunflexo ^ aponta o local aproximado
  • A mensagem descreve o que faltou

Categoria 2

Erros de execução: lendo o traceback

O "rastreamento" mostra o caminho até a falha — leia sempre de baixo para cima.

O programa 
# media.py
idade = int(input("Digite sua idade: "))
print("Você tem", idade, "anos.")
O usuário digita "abc"… 
Traceback (most recent call last):
  File "media.py", line 2, in <module>
    idade = int(input("Digite sua idade: "))
ValueError: invalid literal for int()
with base 10: 'abc'

Como ler

  • Última linha: o tipo do erro (ValueError) + a descrição
  • Linhas de cima: onde ocorreu — arquivo e número da linha
  • Causa aqui: int("abc") — letras não viram número

Outros erros comuns de execução: ZeroDivisionError (dividir por 0) e NameError (usar uma variável que não existe).

Categoria 3

Erros lógicos: o programa "funciona"… errado

Com erro lógico 
nota = 8

if nota >= 5:
    print("Recuperação")
elif nota >= 7:
    print("Aprovado")
else:
    print("Reprovado")

Saída: Recuperação. Nenhum erro é exibido — mas a nota 8 deveria aprovar!

Depurando com perguntas

  • Qual condição verdadeira primeiro? nota >= 5
  • Por que ela "engole" a nota 8? Ordem errada
# correção: do mais restritivo
if nota >= 7: ...   # Aprovado
elif nota >= 5: ... # Recuperação
O programa não "entende a intenção" do programador. Ele executa as condições na ordem escrita.

Conceito 4

try / except: proteger o programa

Em vez de deixar o programa quebrar com uma entrada inválida, tentamos a operação e tratamos a falha.

Estrutura 
try:
    # operação que PODE falhar
    ...
except ValueError:
    # o que fazer SE falhar
    ...

ValueError é o tipo de erro gerado quando uma conversão recebe um valor inadequado — como int("abc").

Exemplo completo 
try:
    idade = int(input("Digite sua idade: "))
    print("Você tem", idade, "anos.")
except ValueError:
    print("Entrada inválida: digite apenas números.")

print("Fim do programa")
Com try/except, digitar "abc" não derruba o programa — ele avisa e continua.

Conceito 4 · continuação

Como o Python decide o caminho

CenárioO que acontece
Digita 20try funciona → bloco inteiro executa → except é ignorado
Digita abcint() falha → salta imediatamente para o except → mensagem exibida

Observações importantes

  • Quando um erro acontece dentro do try, as linhas seguintes do bloco são puladas
  • O except só captura o tipo indicado (aqui, ValueError)
  • Depois do except, o programa segue normalmente

Na Aula 10, combinaremos try/except com while para re-pedir o dado até que seja válido.

Exercício de fixação

Nota validada

O desafio

Tema: combinar conversão segura com decisão.

Tarefa: receber uma nota com input(); se o texto não for número, avisar com try/except; se for, classificar em Aprovado / Recuperação / Reprovado.

Mobiliza: try/except, ValueError, float(), if/elif/else.

Converta dentro do try

Somente a linha que pode falhar precisa de proteção.

Mensagem amigável

"Digite apenas números" — e não o traceback cru.

Classifique só com dado válido

A decisão pode ficar dentro do próprio try, após a conversão.

Teste tudo

"abc", 8.5, 6, 4.9 — entradas válidas e inválidas.

try:
    nota = float(input("Nota: "))
    if nota >= 7:
        print("Aprovado")
    elif nota >= 5:
        print("Recuperação")
    else:
        print("Reprovado")
except ValueError:
    print("Entrada inválida: digite apenas números.")
