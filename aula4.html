Conceito 1

O que é uma variável?

Um nome associado a um valor durante a execução — como cadeiras etiquetadas numa sala: o nome localiza o dado guardado.

A sala de armazenamento 
nome   →  "Marina"
idade  →  19
media  →  8.5
Criação por atribuição 
nome = "Marina"
idade = 19
media = 8.5
= não é igualdade matemática: é atribuição — o valor da direita passa a ser associado ao nome da esquerda.

Conceito 1 · continuação

Atualizando um valor

A segunda atribuição substitui a anterior.

Python 
idade = 19
idade = 20

print(idade)
Saída 
20

Pergunta para a turma: se a variável recebeu primeiro 19 e depois 20, qual deles será exibido? Por quê?

Conceito 2

Regras de nomenclatura

Regras fundamentais

  • Podem conter letras, números e _
  • Não podem começar com número
  • Não podem conter espaços
  • Não podem usar palavras reservadas
  • Diferenciam maiúsculas de minúsculas
Válido 
nome_completo = "Lucas"
idade_aluno = 18
nota1 = 7.5
Inválido 
# 2nota = 8.0    # começa com número
# nome completo  # contém espaço
# class = "ADS"  # palavra reservada
Python diferencia maiúsculas: idade, Idade e IDADE são três variáveis diferentes.

Convenção

snake_case: nomes que contam a história

Em Python, o padrão da comunidade é usar minúsculas e separar palavras com _.

Pouco descritivoMais claro
xidade_aluno
nnome_completo
vvalor_compra
mmedia_final

O nome deve indicar o significado do dado — não sua posição nem seu tipo.

Conceito 3

Tipos de dados primitivos

Python identifica automaticamente o tipo do valor atribuído à variável.

int — inteiro

Números sem parte decimal: 18, 5, 120.

float — decimal

Ponto separa a parte decimal: 1.72, 8.5, 19.90.

bool — lógico

Apenas True e False — sempre com inicial maiúscula.

str — texto

Entre aspas simples ou duplas: "Marina".

Em float, usa-se ponto para separar a parte decimal (8.5, não 8,5).

Atenção

A pegadinha do "18"

Dois valores visualmente parecidos 
idade = 18       # int  → número
idade_texto = "18"  # str  → texto
Comprovando com type() 
print(type(idade))       # <class 'int'>
print(type(idade_texto)) # <class 'str'>
Aspas transformam número em texto. Para o Python, 18 e "18" são coisas completamente diferentes.

Conceito 4

Tipagem dinâmica e a função type()

O tipo acompanha o valor — a variável não fica presa ao primeiro tipo utilizado.

O tipo muda com o valor 
dado = 10
print(type(dado))   # <class 'int'>

dado = "dez"
print(type(dado))   # <class 'str'>
Consultando vários tipos 
nome = "Marina";  altura = 1.68;  matriculado = True

print(type(nome))         # <class 'str'>
print(type(altura))       # <class 'float'>
print(type(matriculado))  # <class 'bool'>
O valor 25 e o valor "25" são iguais para Python? O que muda entre eles?

Conceito 5

Constantes e convenções de escrita

Um valor que, por convenção, não deve mudar durante a execução. Python não trava a variável — quem avisa é o nome em MAIÚSCULAS.

A convenção 
PI = 3.14159
TAXA_JUROS = 0.05
LIMITE_TENTATIVAS = 3
Pi também vem pronto 
import math

print(math.pi)   # 3.14159...

import math acessa recursos matemáticos da biblioteca padrão. Escrever em maiúsculas é um aviso para quem lê e mantém o código.

Boa prática

Comentários: código explicado para pessoas

O interpretador ignora comentários — eles existem para quem lê o código depois (incluindo você).

# — comentário de linha 
# Dados básicos do estudante
nome = "Marina"
idade = 19  # idade atual
Aspas triplas — string multilinha 
"""
Programa de cadastro de estudante.
Armazena nome e idade.
"""

Quando soltas, funcionam como nota explicativa — mas o mecanismo padrão de comentário é #.
