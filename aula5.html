Conceito 1 · continuação

/ vs // e o truque do %

Divisão comum × divisão inteira 
a = 8
b = 3

print(a / b)    # 2.666...  preserva decimais
print(a // b)   # 2         descarta a fração
% — o resto indica paridade 
numero = 10

print(numero % 2)   # 0 → resto zero

Se o resto da divisão por 2 é 0, o número é par. Esse truque será a base para filtrar pares na Aula 10.

Conceito 2

Operadores relacionais

Comparam dois valores e produzem um resultado lógico: True ou False.

OperadorSignificado
==Igual a
!=Diferente de
>Maior que
<Menor que
>=Maior ou igual a
<=Menor ou igual a
Exemplos 
print(10 > 5)    # True
print(10 == 5)   # False
print(10 != 5)   # True
print(7 >= 7)    # True — o limite inclui!
= atribui · == compara. Nunca confunda.

Conceito 3

Operadores lógicos: and, or, not

Combinam ou invertem condições — a tabela-verdade resume todo o comportamento.

ABA and BA or B
TrueTrueTrueTrue
TrueFalseFalseTrue
FalseTrueFalseTrue
FalseFalseFalseFalse

and — verdadeiro somente se ambas forem verdadeiras

or — verdadeiro se pelo menos uma for verdadeira

not — inverte: not True → False

# leitura natural:
# "nota >= 7 E frequência >= 75"
nota >= 7 and frequencia >= 75

Esses operadores ganham uso prático na próxima aula, dentro das estruturas de decisão.

Conceito 4

Ordem das operações

Python respeita a precedência: multiplicação antes da adição.

Sem parênteses 
resultado = 2 + 3 * 4
print(resultado)   # 14
Com parênteses 
resultado = (2 + 3) * 4
print(resultado)   # 20

O computador executa conforme as regras da linguagem. Quando queremos destacar uma parte do cálculo, usamos parênteses.

Conceito 5

Entrada de dados com input()

Python 
nome = input("Digite seu nome: ")
print("Olá,", nome)

idade = input("Digite sua idade: ")
print(type(idade))   # <class 'str'>

O ponto-chave

input() pausa o programa, lê o teclado e devolve o valor… sempre como texto (str).

Mesmo que o usuário digite 20, o valor chega como "20" — texto, não número.

Para calcular, precisamos converter — próximo passo.

Conceito 8

Saída formatada: print() e f-strings

Vírgulas separam valores 
nome = "Marina"
idade = 19

print("Nome:", nome)
print("Idade:", idade)
f-string insere variáveis no texto 
print(f"{nome} tem {idade} anos.")

O prefixo f permite usar { } dentro da string. Extensão útil: f"{total:.2f}" exibe sempre 2 casas decimais — ideal para dinheiro (R$ 37.50).
